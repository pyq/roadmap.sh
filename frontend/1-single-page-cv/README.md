# Single-Page HTML CV

Create a structured, single-page CV using only HTML. Based on [roadmap.sh Single-Page CV project](https://roadmap.sh/projects/single-page-cv).

## Requirements

- [x] Semantic HTML structure
- [x] SEO meta tags
- [x] Open Graph tags
- [x] Favicon link
- [x] Single-page layout

## Getting Started

Open in browser:
```bash
open index.html
```

Or double-click `index.html` in Finder.

## Key Features

**Semantic HTML5 Elements:**
- `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`
- `<time>` with datetime attributes

**SEO & Social Sharing:**
- Meta tags for search engines
- Open Graph tags for social media previews

## Customization

Replace placeholder text with your information:
- Personal details and contact information
- Education, skills, and work experience
- Projects, certifications, and languages
